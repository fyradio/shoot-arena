# 旋風小鬥士 Shoot Legend

3D 戰鬥陀螺對戰遊戲（單檔網頁，可加入手機主畫面離線玩）。

- 遊戲網址：https://fyradio.github.io/shoot-arena/
- 48 顆陀螺分三個等級：神聖（機甲、黃金星座、聖龍、銘刀各 6）、傳說（白銀星座 6、忍者 6、不死鳥、閃電三角箭、四神獸 4）、青銅（原色 6）；16 顆左旋。
- 玩家等級從 Lv1、青銅系列開始；青銅盃 Lv1、傳說盃 Lv3、神聖盃 Lv6，對手用同等級陀螺；賽後隨機抽新陀螺。
- 21 種戰鬥盤、捏臉、斜線分鏡發射、會下降的牆。
- 標題畫面：開始／繼續／重新開始；三種賽制：**積分淘汰**（32 強五關，單人／雙人）、**三戰兩勝**（32 強淘汰，帶三顆陀螺、每關重排順序）、**自由練習**。名次換商店幣。
- 每顆陀螺有專屬必殺走位（星座連線、聖龍蛇行、居合／多連斬／燕返、忍者瞬移、閃電、繞牆、三角、五／六芒星、連擊…），氣滿自動發動，閃電環繞只在必殺時出現；另有「集氣」按鈕。
- **工坊**（含「造型」：自組陀螺花紋、陀螺貼紙、必殺雷電顏色與 7／11／15 道升級）：買陀螺（便宜到貴）、零件盲盒（隨機一顆陀螺的一個零件）、組裝自己的陀螺（可預覽能力）、用增幅道具強化（單項上限 8）。
- 配樂：`music/` 內為 Suno 原創曲剪輯（開場＝片段 1、結算＝片段 6、其餘 16 段戰鬥隨機）。
- 檔案：`index.html`（遊戲）＋ `sw.js`（離線快取，改版時遞增版本號 `V`）＋ `music/`。
- 3D 引擎 three.js r128 由 cdnjs 載入，第一次連網開啟後會被快取，之後可離線。
