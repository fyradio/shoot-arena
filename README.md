# 旋風小鬥士 Shoot Legend

3D 戰鬥陀螺對戰遊戲（單檔網頁，可加入手機主畫面離線玩）。目前版本 **v1.23.0**。

- 遊戲網址：https://fyradio.github.io/shoot-arena/
- **72 顆陀螺、四個等級**：宇宙（24，兩條耐久、覺醒、二段必殺、專屬被動）、神聖（機甲、黃金星座、聖龍、銘刀各 6）、傳說（白銀星座 6、忍者 6、不死鳥、閃電三角箭、四神獸 4）、青銅（原色 6）；四種型態（攻擊／防禦／耐久／平衡）互相克制。
- 玩家等級從 Lv1 開始；青銅盃 Lv1、傳說盃 Lv3、神聖盃 Lv6、宇宙盃 Lv10，對手用同等級陀螺；**以下剋上**：低一級陀螺挑戰高級盃賽，獎勵 ×1.5。
- 戰鬥盤有 9 種特殊效果（黑洞引力、縮圈、旋轉牆、彈簧牆、冰面、熔岩、星際風、隕石雨、加速環）、會下降的牆與道具軌道。
- 三種賽制：**積分淘汰**（32 強五關，單人／雙人）、**三戰兩勝**（8 強淘汰賽，獎勵 ×2，可用全能力強化券）、**自由練習**。名次換商店幣。
- 每顆陀螺有專屬必殺走位，氣滿自動發動；必殺雷電顏色每場隨機搭配。
- 每回合結算可**回放**；特效顏色跟著雙方陀螺。
- **工坊**：買陀螺、零件盲盒、組裝、能力增幅、**造型精靈**（花紋、外環邊緣、內圈、貼紙，貼紙可**自己畫**：對稱畫筆、圖章、描線底圖、填色、魔法潤飾）。
- 遊戲內有「遊戲說明」目錄（戰鬥規則、道具、四種型態、陀螺介紹）。
- 配樂：`music/` 內為 Suno 原創曲剪輯（開場＝片段 1、結算＝片段 6、其餘 16 段戰鬥隨機）。
- 檔案：`index.html`（遊戲）＋ `sw.js`（離線快取）＋ `music/` ＋ `release.json`／`.swver`／`tools/gamerelease.py`（發佈腳本）。
- 3D 引擎 three.js r128 由 cdnjs 載入，第一次連網開啟後會被快取，之後可離線。

## 發佈
`python3 tools/gamerelease.py release.json "更新說明" [patch|minor|major|none]`：語法檢查 → 版本號 +1 → `sw.js` 版本 +1 → 產生 `index.html`／`sw.js` → commit/push。原始碼 `spin.html` 在開發環境，不在這個儲存庫。
